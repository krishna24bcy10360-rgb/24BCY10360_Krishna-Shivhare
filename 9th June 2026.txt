/* ============================================================================
TROUBLESHOOTING NOTE FOR LAB EVALUATION:
============================================================================
The error "MongoServerError[NoReplicationEnabled]" occurs because the 
mongod daemon process was initially launched as a standalone instance.

To fix this before executing the deployment script below, all database 
instances must be restarted from the terminal/command prompt with the 
replicated cluster flag enabled:

  mongod --port 27017 --dbpath "data/db1" --replSet "myReplSet"
  mongod --port 27018 --dbpath "data/db2" --replSet "myReplSet"
  mongod --port 27019 --dbpath "data/db3" --replSet "myReplSet"
============================================================================
*/
